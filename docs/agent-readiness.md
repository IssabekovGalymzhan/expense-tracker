# Agent-Readiness Audit

## Level: 2 - Documented

The repository has a README, a repository map, an `AGENTS.md` file, explicit safe and
forbidden operations, acceptance criteria and a one-command test suite. Dependencies
are limited to the Python standard library, making setup reproducible with Python 3.13.1.

Level 3 was not assigned because the repository has no configured linter, type checker,
CI workflow or build command. Logging and end-to-end CLI tests are also minimal.
